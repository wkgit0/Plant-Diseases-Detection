Plant Diseases Detection 🍃 is a deep learning-based project developed using PyTorch that aims to identify diseases in plant leaves through image classification. It uses a Convolutional Neural Network (CNN) trained on the PlantVillage dataset, which includes thousands of labeled images of healthy and diseased leaves. The model achieves high accuracy and can be used for real-time predictions, helping farmers and researchers detect plant diseases early. To use the project, simply clone the repository, install the dependencies listed in requirements.txt, and run the train.py script to train the model. You can then use predict.py to analyze new leaf images.
