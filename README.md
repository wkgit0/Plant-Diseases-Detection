**🌿 Plant Diseases Detection**
A deep learning-based system to identify plant leaf diseases using image classification with PyTorch.

**🚀 Features**
Detects multiple plant diseases from leaf images

Trained on the PlantVillage dataset

Built with CNN using PyTorch

High accuracy and real-time predictions

**🛠️ Usage**
bash
Copy
Edit
Clone the repo
git clone https://github.com/yourusername/plant-disease-detection.git
cd plant-disease-detection

**Install dependencies**
pip install -r requirements.txt

**Train the model**
python train.py

**Predict a new image**
python predict.py --image path_to_image.jpg

🌱 PlantVillage on Kaggle
